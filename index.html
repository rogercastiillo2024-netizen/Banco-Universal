Módulos de Prácticas de Ciberseguridad

1. SQL Injection (SQLi) Ataque Crítico

Prueba: Activa el switch "Modo SQL Vulnerable" en el Login e ingresa como usuario:
' OR '1'='1 o admin' --
Explicación: Ocurre cuando los datos del usuario se concatenan directamente a la consulta SQL sin sanitizar, alterando la lógica booleana del servidor.

2. Cross-Site Scripting (XSS) Inyección

Prueba: En la transferencia, en el campo "Concepto", intenta escribir:
<b style="color:red">Prueba XSS</b>
Explicación: Observa cómo el sistema escapa los caracteres especial (`<`, `>`) usando sanitización para evitar ejecución de scripts maliciosos.

3. Hash de Contraseñas vs Texto Plano Criptografía

Inspecciona la tabla USERS abajo. Las contraseñas nunca deben guardarse en texto plano. En una base de datos real se usa Bcrypt/Argon2 con Salt.
